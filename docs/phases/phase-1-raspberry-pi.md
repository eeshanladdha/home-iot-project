# Phase 1: Raspberry Pi Foundation

## Objective
Build a stable Raspberry Pi/Linux foundation for all later phases.

## Scope
- Raspberry Pi model and OS
- Storage and power
- Network and SSH
- Users and permissions
- Python and Git
- Docker evaluation
- Monitoring and backup
- Logging and update strategy

## LLD placeholders
Runtime, network, services, observability and backup design remain TBD until the exact hardware and environment are available.

## Exit criteria
- [ ] OS installed
- [ ] Network stable
- [ ] SSH secured
- [ ] User model established
- [ ] Python environment ready
- [ ] Git workflow tested
- [ ] Docker decision recorded
- [ ] Monitoring baseline established
- [ ] Backup/recovery tested
